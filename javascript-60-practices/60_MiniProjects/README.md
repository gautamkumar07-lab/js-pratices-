# Capstone Mini-Projects (Interactive Suite)

Bring all 59 concepts together into 6 full-fledged, runnable interactive mini-projects with zero external dependencies.


### Capstone: 6 Real-World Interactive Mini-Projects
The final topic in your 60-topic journey combines everything you have learned (Variables, Control Flow, Functions, Closures, DOM Manipulation, Event Listeners, LocalStorage, Async/Promises, Classes, and Array transformations) into real, working applications:

1. **Task Matrix / Todo App**: Real-time CRUD, status filtering, and local storage persistence.
2. **High-Precision Lap Stopwatch**: Accurate time delta math, millisecond rendering, lap splits.
3. **Interactive Live Form Validator**: Real-time regex testing, constraint checking, and visual cues.
4. **Expense Splitter & Tip Calculator**: Dynamic bill calculation, tip percentage sliders, and per-person breakdown.
5. **Color Palette Generator & Contrast Inspector**: Random hex color algorithms and WCAG luminance calculations.
6. **Speed Quiz Engine**: Dynamic timer, question indexing, score calculation, and review.
