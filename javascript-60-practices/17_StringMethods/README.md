# String Methods (trim, slice, replaceAll, split)

Master essential text manipulation methods: search, slice, replaceAll, padding, and splitting.


### Essential String Methods
- `trim()`, `trimStart()`, `trimEnd()`: Strips whitespace.
- `slice(start, end)`: Extracts a section of a string.
- `split(separator)`: Splits string into an array of substrings.
- `replace(substr, replacer)`, `replaceAll()`: Replaces occurrences.
- `includes(search)`, `startsWith()`, `endsWith()`: Boolean searches.
- `padStart(length, char)`, `padEnd()`: Formats numbers/dates with leading padding.
