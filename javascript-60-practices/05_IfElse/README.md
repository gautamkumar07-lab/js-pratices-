# If...Else & Ternary Operator

Multi-branch conditional logic, guard clauses, and concise inline conditional ternary expressions.


### If...Else Branching
`if...else if...else` executes different code blocks based on consecutive conditional tests.

### Guard Clauses
Instead of deeply nested `if...else` trees, use early `return` statements to handle error/edge cases first.

### Ternary Operator (`condition ? exprIfTrue : exprIfFalse`)
An expression (returns a value) suitable for concise inline assignments.
