# Rest Operator / Parameters (...)

Gather multiple elements or arguments into a single structured array.


### Spread vs Rest
Although both use the three dots (`...`), their roles are exact opposites:
- **Spread**: unpacks / expands values into multiple individual elements.
- **Rest**: gathers multiple individual values into a single array!

### Rules for Rest Parameters:
- Must be the **last** parameter in a function definition.
- A function can only have **one** rest parameter.
