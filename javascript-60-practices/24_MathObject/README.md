# Math Object & Numeric Operations

Built-in mathematical constants, rounding algorithms (floor, ceil, round, trunc), and random range generation.


### The Math Object
A static built-in object providing mathematical constants and utility functions:
- Constants: `Math.PI`, `Math.E`
- Rounding:
  - `Math.floor(x)`: rounds down
  - `Math.ceil(x)`: rounds up
  - `Math.round(x)`: rounds to nearest integer
  - `Math.trunc(x)`: removes fractional digits
- Random: `Math.random()` returns float in `[0, 1)`
- Utilities: `Math.min()`, `Math.max()`, `Math.abs()`, `Math.pow()` / `**`, `Math.sqrt()`
