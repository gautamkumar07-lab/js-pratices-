# For Loop (Classic, for...of, for...in)

Master the classic indexed for loop, for...of (iterables), and for...in (object keys) iteration.


### Types of For Loops in JavaScript:

1. **Classic `for` Loop**:
   `for (let i = 0; i < len; i++)` — Ideal when you need index-based iteration or precise control.

2. **`for...of` Loop (ES6)**:
   Iterates over **values** of an iterable (Arrays, Strings, Sets, Maps, NodeLists). Cleanest for arrays!

3. **`for...in` Loop**:
   Iterates over **enumerable string keys** of an object (including inherited prototype keys). **Do NOT use for arrays!**
