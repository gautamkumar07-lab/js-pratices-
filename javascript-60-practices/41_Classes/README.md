# Classes (ES6 Syntax & Class Fields)

Object-oriented programming with ES6 classes, public instance fields, and modern private fields (#field).


### ES6 Classes
Syntactic sugar over JavaScript's existing prototype-based inheritance.

### Modern Features (ES2022+):
1. **Public Class Fields**: Declared directly on the class body without constructor.
2. **Private Fields (`#privateField`)**: Enforced by the JavaScript engine at the language level! Cannot be accessed or modified from outside the class instance.
