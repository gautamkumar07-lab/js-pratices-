# If Statement & Truthy / Falsy

Learn conditional branching and the exact rules of truthiness and falsiness in JavaScript.


### The If Statement
The `if` statement executes a code block if a specified condition evaluates to truthy.

### The 8 Falsy Values in JavaScript:
Any value that is not one of these 8 is **truthy**:
1. `false`
2. `0` (and `-0`, `0n`)
3. `""` (empty string)
4. `null`
5. `undefined`
6. `NaN`
7. `document.all` (browser quirk)
8. `0n` (BigInt zero)

*Notice:* `[]` (empty array) and `{}` (empty object) are **TRUTHY**!
