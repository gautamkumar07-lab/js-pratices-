# Data Types (Primitives & Reference)

Understand the 7 primitive types and reference types in JavaScript, including memory representation and type coercion.


### JavaScript Type System
JavaScript is dynamically and weakly typed. Types are divided into:

#### 1. Primitive Types (Passed by value, immutable):
- **`string`**: text sequences (e.g., `"hello"`)
- **`number`**: 64-bit float IEEE 754 (e.g., `42`, `3.14`, `NaN`, `Infinity`)
- **`bigint`**: arbitrary precision integers (`100n`)
- **`boolean`**: `true` or `false`
- **`undefined`**: variable declared but unassigned
- **`null`**: intentional absence of any object value
- **`symbol`**: unique, immutable identifier for object keys

#### 2. Reference Types (Passed by reference, mutable):
- **`Object`**, **`Array`**, **`Function`**, **`Date`**, **`Map`**, **`Set`**
