# Arrays (Creation, Indexing, Mutability)

Ordered collections of values, dynamic sizing, indexing, and basic mutation operations.


### What is an Array in JavaScript?
Arrays are special object types designed for ordered lists of data. Elements are zero-indexed and can store mixed data types.

### Key Characteristics:
- **Zero-indexed**: First element at index `0`.
- **Dynamic length**: Automatically adjusts when adding/removing elements.
- **Reference type**: Stored by reference in memory. Mutating an array affects all variables pointing to that reference.
