# While Loop

Execute code repeatedly as long as a specified test condition evaluates to truthy.


### The While Loop
Evaluates the condition **before** entering each iteration. If the condition is false initially, the body will never run.

### Syntax:
```js
while (condition) {
  // body
  // step modifying condition
}
```

### Preventing Infinite Loops:
Ensure the body of the loop modifies state towards satisfying the loop termination condition!
